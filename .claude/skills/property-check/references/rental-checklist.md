# 賃貸物件チェックリスト

## A. 募集情報の段階でわかる地雷サイン

| サイン | 疑われること | 確かめ方 |
|---|---|---|
| 相場より1〜2割以上安い | 事故物件、おとり物件、騒音・日当たり不良、定期借家 | 理由を不動産会社に直接聞く。告知事項の有無を書面で確認 |
| 「告知事項あり」「心理的瑕疵」 | 事故物件 | 内容と時期を具体的に聞く |
| 定期借家契約 | 期間満了で退去（更新できない場合あり） | 再契約の可否と条件を確認 |
| 短期解約違約金（例: 1年未満は家賃1か月分） | 短期で出ると違約金 | 契約期間と金額を確認 |
| フリーレントが長い・初期費用ゼロ | 空室が埋まらない理由がある、短期解約違約金とセットのことが多い | 違約金条項と空室期間を確認 |
| 同じ部屋・同じ建物が頻繁に募集されている | 騒音・住人トラブル・設備不良で人が定着しない | 建物名で検索、ポータルの過去掲載を見る |
| 写真が少ない・外観がない・住所がぼかしてある | おとり物件 | 建物名・所在地を聞く、他社に空室確認 |
| プロパンガス | ガス代が都市ガスより高くなりがち | ガス会社と従量単価を聞く |
| 「インターネット無料」 | 回線が共用で遅いことがある | 回線方式（光配線 / VDSL / LAN）を聞く |
| 1階・半地下・北向き | 湿気・カビ・防犯・日当たり | 内見で確認 |
| 線路沿い・幹線道路沿い・繁華街 | 騒音・振動・排ガス・治安 | 窓を閉めた状態の音、夜の様子 |
| 木造・軽量鉄骨のアパート | 生活音が聞こえやすい | 壁ノック、角部屋・最上階を選ぶ |

### 構造と音の目安
- 木造・軽量鉄骨: 隣室のテレビ・話し声・生活音が聞こえやすい
- 重量鉄骨: 軽量鉄骨よりはまし
- RC・SRC: 空気を伝わる音には強いが、上階の足音（床衝撃音）は聞こえることがある
- 同じRCでも、壁がコンクリート直仕上げか、石膏ボードを貼ったGL工法かで差が出る

## B. 内見チェックリスト

### 持ち物
メジャー（家具・家電の寸法、搬入経路）、スマホ（コンパス・水平器アプリ・カメラ・電波確認）、間取り図、筆記具、（あれば）ビー玉

### 室内
- [ ] 隣室と接する壁を軽くノック（「コンコン」と軽い＝石膏ボードのみの可能性。場所で音が変わる＝GL工法の可能性）
- [ ] 窓を閉めた状態・開けた状態で外の音を聞く
- [ ] 上階の足音が聞こえないか（数分静かにして聞く）
- [ ] 日当たり・方角（コンパスで確認）、向かいの建物との距離
- [ ] 結露跡・カビ（窓まわり、押し入れ・クローゼットの奥、北側の壁の下部）
- [ ] 床の傾き・きしみ
- [ ] 水回り: 水圧、排水の流れ、排水口のにおい、水漏れ跡（シンク下・洗面台下）
- [ ] 換気扇・エアコン（年式、動作、カビのにおい）、給湯器の年式
- [ ] 収納・洗濯機置き場・冷蔵庫置き場の寸法、コンセントの位置と数
- [ ] 携帯電話の電波（各部屋で）
- [ ] 網戸・鍵（ディンプルキーか、鍵交換されるか）
- [ ] 天井・壁のシミ（雨漏り・上階からの漏水）
- [ ] 室内のにおい（タバコ、ペット、下水、カビ）
- [ ] 家具・家電の搬入経路（玄関、廊下、階段、エレベーターの幅）

### 共用部（住人の質と管理状態が出る）
- [ ] ゴミ置き場: 分別されているか、散らかっていないか、粗大ゴミの放置
- [ ] 集合ポスト: チラシがあふれていないか、テープで塞がれたポストが多くないか
- [ ] 掲示板: 騒音・ゴミ・喫煙・ペットなどの苦情や注意書きが多くないか
- [ ] 駐輪場: 放置自転車、整理されているか
- [ ] 廊下・階段: 私物の放置、照明切れ、汚れ
- [ ] エントランスのオートロック・防犯カメラ
- [ ] 隣室・上下階の様子（玄関前の物、表札の雰囲気）

### 周辺
- [ ] 駅からの道のり（実際の所要時間、坂、街灯、人通り、夜道の安全）
- [ ] スーパー・コンビニ・病院・ドラッグストアの距離
- [ ] 近くの騒音・においの元（線路、幹線道路、工場、飲食店、学校、公園）
- [ ] 目の前の空き地・駐車場、建築計画のお知らせ看板
- [ ] **時間帯・曜日を変えて再訪**（夜、休日）

## C. 不動産会社に聞くこと

- 前の入居者の退去理由、どれくらい空室だったか
- 告知事項（事件・事故・自殺・孤独死など）の有無 ※ガイドライン上告知義務がない場合もあるので、聞かれれば答える範囲で確認
- 騒音トラブル・住人トラブルの有無、どんな人が住んでいるか（単身 / ファミリー / 学生）
- 管理会社と、トラブル時の連絡先・対応時間
- 設備故障時の修理負担
- 家賃交渉・初期費用交渉の余地
- 周辺の建築予定

## D. 契約前チェック（重要事項説明・契約書）

### 初期費用の明細
- [ ] 敷金・礼金・仲介手数料（原則 家賃の0.5か月分＋税、借主の承諾があれば最大1か月分＋税）
- [ ] 前家賃・日割り家賃
- [ ] 保証会社の初回保証料・更新保証料
- [ ] 火災保険（指定か、自分で選べるか）
- [ ] 鍵交換費
- [ ] 消毒・抗菌・消臭、24時間サポート、安心入居サポート等 → **任意のことが多い。外せるか聞く**

### 契約条件・特約
- [ ] 契約の種類（普通借家 / 定期借家）と期間
- [ ] 更新料・更新事務手数料
- [ ] 解約予告期間（1か月前 / 2か月前）
- [ ] 短期解約違約金の有無と金額
- [ ] 退去時のクリーニング費・鍵交換費などの借主負担特約
- [ ] 原状回復の範囲（国交省「原状回復をめぐるトラブルとガイドライン」と照らし合わせる。通常損耗・経年劣化は原則貸主負担だが、明確な特約があれば従う必要がある）
- [ ] 禁止事項（ペット、楽器、喫煙、事務所利用、二人入居）
- [ ] 敷金の返還条件

### 入居時
- [ ] 入居時に傷・汚れを日付入りで写真に撮り、管理会社に共有（退去時の原状回復トラブル防止）
