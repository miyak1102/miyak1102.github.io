# 購入物件チェックリスト（賃貸チェックリストに追加で確認）

内見・周辺環境・災害リスクの確認は `rental-checklist.md` と `sites.md` を共通で使う。ここでは購入特有の項目をまとめる。

## A. 共通の地雷サイン

| サイン | リスク | 確かめ方 |
|---|---|---|
| 建築確認が1981年5月31日以前（旧耐震） | 耐震性、住宅ローン減税・融資の条件、将来の売りにくさ | 建築確認日を確認（竣工日ではなく確認日）。耐震診断・耐震改修の有無 |
| 浸水想定区域・土砂災害警戒区域・液状化・盛土 | 災害リスク、保険料、資産価値 | `sites.md` の災害リスク欄。重要事項説明でも水害ハザードマップ上の位置の説明が義務 |
| 相場より明らかに安い | 事故、再建築不可、借地権、管理不全、旧耐震、告知事項 | 理由を説明してもらう |
| 借地権（地上権・賃借権） | 地代・更新料・建替え承諾料、融資が付きにくい | 契約期間・地代・承諾料を確認 |
| 検査済証がない | 違反建築の可能性、融資・増改築に影響 | 台帳記載事項証明書で確認 |

## B. 中古マンション（「マンションは管理を買え」）

### 入手する資料（仲介会社経由で依頼）
- **重要事項調査報告書**: 管理費・修繕積立金の額、滞納の有無と総額、修繕積立金の残高、借入金、大規模修繕の予定
- **長期修繕計画書**: いつ・何に・いくらかかるか、何年ごとに見直しているか
- **総会・理事会の議事録**（直近2〜3年分）: 住民トラブル、漏水事故、修繕積立金の値上げ議論、管理会社変更、訴訟
- **管理規約・使用細則**: ペット、楽器、民泊、リフォームの制限
- 修繕履歴（外壁、屋上防水、給排水管、エレベーター）

### 地雷サイン
- [ ] 修繕積立金が相場より極端に安い、または「段階増額方式」で将来大幅に上がる予定
- [ ] 修繕積立金の残高が長期修繕計画に対して不足、一時金徴収の予定
- [ ] 管理費・修繕積立金の滞納が多い
- [ ] 長期修繕計画が何年も見直されていない、または存在しない
- [ ] 自主管理（管理会社なし）で、役員のなり手がいない
- [ ] 総戸数が少ない（1戸あたりの負担が大きい）
- [ ] 賃貸化・空室率が高い、民泊が多い
- [ ] 機械式駐車場の空きが多い（維持費が管理組合の負担に）
- [ ] 共用部が荒れている（ゴミ置き場、郵便受け、掲示物、照明切れ、ひび割れ・鉄部のサビ）
- [ ] 大規模修繕が予定より大幅に遅れている

### 良いサイン
- 長期修繕計画が5年程度ごとに見直され、積立金が計画に見合っている
- 管理計画認定（自治体）やマンション管理適正評価を取得している
- 議事録で住民が活発に議論し、問題に対処している
- 管理人の勤務形態が明確で、共用部が清潔

## C. 戸建て・土地

- [ ] **接道**: 建築基準法上の道路に2m以上接しているか（接していなければ再建築不可）
- [ ] **セットバック**: 前面道路が4m未満なら敷地の一部を道路として提供する必要
- [ ] **境界**: 境界標・確定測量図の有無、越境物（塀・樹木・屋根）
- [ ] **擁壁・がけ**: 高さ2m超の擁壁は検査済みか、ひび・膨らみ・水抜き穴の詰まり。がけ条例の対象か
- [ ] **地盤**: 旧地形（田・沼・川）、液状化、盛土。地盤調査報告書の有無
- [ ] **インフラ**: 上下水道の引き込み管（前面道路の本管から引き込まれているか、他人の土地を通っていないか）、都市ガスかプロパンか、浄化槽か
- [ ] **建物**: 既存住宅状況調査（インスペクション）、雨漏り・シロアリ・基礎のひび・床の傾き、増改築の履歴
- [ ] **私道**: 持分の有無、通行・掘削の承諾書
- [ ] **用途地域と建ぺい率・容積率**: 既存建物が超過していないか（違反建築）、隣地に何が建ちうるか
- [ ] **市街化調整区域**: 原則として建築・建替えに制限

## D. 購入の契約前に確認すること

- [ ] 重要事項説明書を**契約日より前に**受け取り、読んでおく（説明は契約当日にまとめて行われがち）
- [ ] 契約不適合責任の期間と範囲（売主が個人の場合「免責」もある）
- [ ] 住宅ローン特約（ローンが通らなかった場合の白紙解約）
- [ ] 手付金の額と手付解除の期限
- [ ] 告知書（物件状況報告書）: 雨漏り、シロアリ、事件・事故、近隣トラブル
- [ ] 付帯設備表: 何が引き渡されるか、故障の有無
- [ ] 固定資産税・管理費の精算方法、諸費用の総額
- [ ] 住宅ローン減税・各種優遇の適用可否（築年・耐震・省エネ性能）
