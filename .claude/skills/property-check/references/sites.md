# 物件調査に使うサイト一覧

公的サイトを優先し、民間・非公式サイトは補助として使う。
URLやサイト構成は変わることがあるので、つながらない場合はサイト名で検索する。

## 1. 災害リスク

| サイト | わかること | 使い方のコツ |
|---|---|---|
| **重ねるハザードマップ**（国交省・国土地理院 ハザードマップポータルサイト）<br>https://disaportal.gsi.go.jp/ | 洪水・内水氾濫・高潮・津波の浸水想定区域と浸水深、土砂災害警戒区域、地形分類 | 住所を入れて「洪水」「土砂災害」「津波」などを重ねる。洪水は「想定最大規模」が初期表示、「計画規模」も切り替えて比べる。住所指定で「災害リスクレポート」も出せる |
| **わがまちハザードマップ**（同サイト内） | 市区町村が作った詳細なハザードマップ（避難所、内水など） | 重ねるハザードマップより細かいことがある。自治体版も必ず見る |
| **地理院地図**<br>https://maps.gsi.go.jp/ | 治水地形分類図（旧河道・後背湿地など）、土地条件図、過去の空中写真、大規模盛土造成地 | 「土地の成り立ち・土地利用」レイヤー。旧河道・湿地・盛土は浸水・液状化・地盤沈下リスクのサイン |
| **今昔マップ on the web**<br>https://ktgis.net/kjmapw/ | 明治〜昭和の旧版地形図と現在の地図の比較 | 物件の場所が昔「田」「沼」「池」「川」だったか確認。地名に水辺を示す字（沼・池・谷・沢・窪・洲など）がある場合も参考に |
| **J-SHIS 地震ハザードステーション**（防災科研）<br>https://www.j-shis.bosai.go.jp/ | 今後30年に震度6弱以上の揺れに見舞われる確率、表層地盤の揺れやすさ | 地区単位で比較できる |
| **地盤サポートマップ**（民間）<br>https://supportmap.jp/ | 地盤の揺れやすさ、液状化可能性、近隣の地盤調査結果の傾向 | 戸建て購入で特に有用 |
| 自治体の**液状化予測図・大規模盛土造成地マップ** | 液状化危険度、盛土の位置 | 「◯◯市 液状化」「◯◯市 大規模盛土造成地」で検索 |

## 2. 価格・家賃の相場

| サイト | わかること | 使い方のコツ |
|---|---|---|
| **不動産情報ライブラリ**（国交省）<br>https://www.reinfolib.mlit.go.jp/ | 実際の取引価格（アンケート）と成約価格（レインズ由来）、地価公示、ハザード・都市計画・周辺施設も地図で重ねられる | 購入の相場確認の基本。町字単位で表示される。用途地域・学校区・人口推計なども同じ地図で見られる |
| **レインズ・マーケット・インフォメーション**<br>https://www.contract.reins.or.jp/ | マンション・戸建ての成約価格 | 「売り出し価格」ではなく「成約価格」で比べられる |
| **全国地価マップ**<br>https://www.chikamap.jp/ | 公示地価・路線価・固定資産税路線価 | 土地・戸建て向け |
| SUUMO・HOME'S・at home 等のポータル | 同条件の募集賃料・売出価格 | 同じ駅・徒歩分数・築年数・面積・構造で10件ほど比べる。**同じ建物の他の部屋や過去の募集**も見る |

### 家賃相場の比べ方
1. 同じ駅・徒歩±3分・築年±5年・面積±5㎡・同じ構造で絞る
2. 管理費・共益費込みで比較する
3. 対象物件が相場より1〜2割以上安ければ、理由を探す（事故物件、おとり、定期借家、騒音、1階・北向き、旧耐震など）

## 3. 事故物件・おとり物件・業者の確認

| サイト | わかること | 使い方のコツ |
|---|---|---|
| **大島てる**（民間・非公式）<br>https://www.oshimaland.co.jp/ | 事件・事故・自殺などがあったとされる物件の投稿情報 | 住所で地図を見る。投稿ベースで正確性の保証はない。気になれば不動産会社に書面で確認 |
| **宅地建物取引業者による人の死の告知に関するガイドライン**（国交省） | 告知が必要な範囲・期間 | 自然死・日常生活の不慮の死は原則告知不要。特殊清掃等があった場合や自殺・他殺等は賃貸で概ね3年告知 |
| **建設業者・宅建業者等企業情報検索システム**（国交省）<br>https://etsuran2.mlit.go.jp/TAKKEN/ | 仲介会社の宅建業免許の有無・免許番号 | 免許番号の（ ）内の数字は更新回数。大臣免許は国交省、知事免許は都道府県のサイトにも載る |
| **ネガティブ情報等検索サイト**（国交省）<br>https://www.mlit.go.jp/nega-inf/ | 宅建業者の行政処分歴 | 社名で検索 |
| 建物名・住所での Web 検索 | 過去の募集履歴、口コミ、ニュース | 「建物名 + 騒音」「建物名 + 口コミ」なども試す。同じ部屋が何度も募集されていたら入居者が定着しない理由がある可能性 |

### おとり物件のサイン
- 相場より明らかに安い、条件が良すぎる
- 写真が少ない・外観写真がない・住所や建物名がぼかしてある
- 問い合わせると「申し込みが入った」「まず来店を」と言われ、内見を渋る
- 取引態様が「仲介（先物）」で、長期間掲載され続けている
- 同じ物件を他の不動産会社に問い合わせると、すでに成約済みと言われる
→ 他社に空室確認する、建物名で検索する、来店前に「内見可能か」を確認する

## 4. 周辺環境

| サイト | わかること | 使い方のコツ |
|---|---|---|
| **警視庁 犯罪情報マップ**（東京都）<br>https://www.keishicho.metro.tokyo.lg.jp/jiken_jiko/hassei/map_annai.html | 町丁目単位の侵入窃盗・ひったくり・自転車盗・痴漢などの発生状況 | ランキングではなく「どの種類の犯罪が多いか」を見る。他府県も「◯◯県警 犯罪情報マップ」で検索 |
| 都道府県警の**不審者情報・メール配信** | 声かけ・つきまといなどの直近情報 | 子育て・一人暮らし女性は特に |
| 自治体の**都市計画図（用途地域）**、または不動産情報ライブラリの都市計画レイヤー | 周りにどんな建物が建ちうるか | 商業・準工業・工業地域は大型建物・工場・夜間営業店ができうる。目の前の空き地・駐車場は将来高い建物が建つ可能性 |
| Google マップ / ストリートビュー | 駅からの道、坂、街灯、周辺の店・施設、**過去の画像** | ストリートビューの過去画像で、以前の様子（建物の変化、看板、ゴミ置き場の荒れ）を確認 |
| 自治体の**ごみ分別・子育て支援・学校区**のページ | 生活ルール、行政サービス | 子育て世帯は保育園の空き状況・学校区も |

### 現地で確かめる（サイトではわからないこと）
- 平日夜・休日昼など **時間帯と曜日を変えて** 周辺を歩く（騒音、人通り、たまり場、街灯）
- 近くの建築計画のお知らせ看板（標識）
- 線路・幹線道路・飲食店・工場からの音とにおい
- 携帯電話の電波（室内で確認）

## 5. 購入時に追加で見るもの

| 資料・サイト | わかること |
|---|---|
| **登記事項証明書**（法務局 / 登記情報提供サービス https://www1.touki.or.jp/） | 所有者、抵当権、地目の履歴（昔は田・沼地だったか） |
| 自治体の**建築計画概要書・台帳記載事項証明書** | 建築確認・検査済証の有無、建築確認日（旧耐震の判定） |
| 自治体の**道路台帳・指定道路図** | 接道（建築基準法上の道路か、再建築できるか） |
| **重要事項調査報告書**・**長期修繕計画**・**総会議事録**（マンション、仲介会社経由で入手） | 管理費・修繕積立金の滞納、計画の見直し状況、大規模修繕の予定、住民トラブル |
| **マンション管理計画認定制度**（自治体）、**マンション管理適正評価制度**（マンション管理業協会） | 管理状態が一定水準と評価されているか |
| **既存住宅状況調査（インスペクション）** | 建物の劣化・雨漏り・構造の不具合の有無 |
