# 物件チェック（良い物件 / 地雷物件の見極め）

物件選びの失敗は「事前に調べられたのに調べなかった」ことが原因であることが多い。
このスキルは **①机上調査 → ②内見 → ③契約書類** の3段階で、確認すべき項目と使うサイトを体系的に洗い出す。

## 使う参照ファイル

- `references/sites.md` … 調査に使うサイト一覧（何がわかるか・URL・使い方）
- `references/rental-checklist.md` … 賃貸の地雷サインと内見・契約チェックリスト
- `references/purchase-checklist.md` … 購入（中古マンション・戸建て・土地）の追加チェック項目

まず必要な参照ファイルだけ読む。賃貸なら `sites.md` + `rental-checklist.md`、購入なら3つすべて。

## ワークフロー

### 0. 前提情報をそろえる

ユーザーから以下を聞く（わかる範囲でよい。不足は推測せず「未確認」と書く）:

- 賃貸か購入か / マンション・アパート・戸建て・土地
- 住所（町丁目まで）・建物名・部屋番号・階数・向き
- 築年月・構造（木造 / 軽量鉄骨 / 重量鉄骨 / RC / SRC）・総戸数
- 賃料（管理費込み）または価格・面積・間取り
- 掲載サイトのURL、募集図面（マイソク）の画像があればそれも
- 本人の優先条件（通勤先、予算上限、静かさ、日当たり、ペット、子育て など）

物件URLが渡されたら、取得できる範囲で募集情報を読み取って上の項目を埋める。

### 1. 机上調査（内見前にやる）

`references/sites.md` の順に調べる。WebSearch / WebFetch が使えるならできるものは自分で調べ、
地図操作が必要で取得できないものは **「このURLで、この住所を入れて、このレイヤーを見る」** と具体的に案内する。

必ずカバーする観点:

1. **災害リスク** … 洪水・内水・高潮・津波・土砂災害・地震の揺れやすさ・液状化・盛土。旧地形（元は田・沼・川か）
2. **相場との比較** … 近隣の同条件と比べて安すぎ / 高すぎないか。安すぎる場合は理由を必ず探す
3. **事故物件・おとり物件の疑い** … 相場より極端に安い、同じ部屋が頻繁に募集されている、建物名で検索して過去の情報が出るか
4. **周辺環境** … 治安（犯罪情報マップ）、用途地域（近くに工場・幹線道路・大型建築の可能性）、嫌悪施設、駅からの実際の道のり（坂・街灯・人通り）
5. **建物の素性** … 構造と築年（1981年6月以前の建築確認は旧耐震）、管理会社、建物名での口コミ・過去の募集履歴
6. **業者の確認** … 仲介会社の宅建業免許番号と行政処分歴

### 2. 内見チェックリストを作る

`rental-checklist.md` / `purchase-checklist.md` から、この物件に関係する項目だけを抜き出し、
机上調査で気になった点（例: 浸水想定あり → 1階の床下・排水、幹線道路沿い → 窓を閉めた時の音）を
**この物件専用の質問・確認項目** として追加する。持ち物（メジャー、スマホのコンパス・水平器アプリ、ビー玉、充電器）も添える。

「時間帯・曜日を変えて周辺を歩く（夜・休日）」は必ず入れる。

### 3. 契約前チェック

初期費用の明細、特約、重要事項説明書で見るべき箇所を示す。
賃貸は特に「短期解約違約金」「定期借家か」「退去時クリーニング等の特約」「任意の付帯サービス（消毒・安心サポート等）」「更新料」。
購入は「重要事項調査報告書」「長期修繕計画」「総会議事録」「インスペクション」「再建築可否・接道」。

### 4. レポートを出す

以下の形式でまとめる:

```
## 物件チェック結果: <物件名 / 住所>

### 総合判定
🟢 大きな問題なし / 🟡 要確認あり / 🔴 地雷の可能性が高い
（一言で理由）

### 🔴 重大な懸念
- <項目>: <何がわかったか>（出典: <サイト名・URL>）

### 🟡 要確認（内見・問い合わせで確かめる）
- <項目>: <なぜ気になるか> → <どう確かめるか>

### 🟢 良い点

### 調べられなかった項目
- <項目>: <自分で確認する方法とURL>

### 内見チェックリスト（この物件用）
- [ ] ...

### 不動産会社に聞くこと
- ...
```

## 判断の原則

- **安いには理由がある。** 相場より1〜2割以上安い場合は、事故物件・おとり・騒音・災害リスク・旧耐震・定期借家・再建築不可などのどれかを疑い、理由が説明できるまで🟡以上にする。
- **事実と推測を分ける。** サイトで確認した事実には出典を付け、推測は「〜の可能性」と書く。調べられなかったことを「問題なし」と書かない。
- **非公式情報の扱い。** 事故物件サイトや口コミは正確性の保証がない。参考情報として扱い、最終的には不動産会社に書面（告知事項）で確認するよう勧める。
- **告知義務の範囲を知っておく。** 国交省ガイドライン（2021年10月）では、自然死・日常生活の不慮の死は原則告知不要、特殊清掃等が行われた場合や自殺・他殺等は賃貸で概ね3年間告知。つまり「告知なし＝何もなかった」ではない。
- **管理を見る。** 共用部（ゴミ置き場・郵便受け・掲示板・駐輪場）は住人の質と管理状態を正直に映す。購入では「マンションは管理を買え」。
- **最終判断はユーザー。** 優先条件によって許容できるリスクは変わる。リスクを並べたうえで、本人の条件に照らした見解を述べる。法的判断が必要な場合は宅建士・弁護士・自治体の相談窓口を案内する。
